# Clothes Hanger

- **Year:** 2023
- **Context:** Personal project

## Summary

Designed a modular, 3D-printed clothing tree with snap-together joints that retain each section while allowing rotation. Print-bed-sized components, branching pole sections, and joint covers support a configurable design with minimal printing supports.

## Objective

Explore a freestanding clothing organizer assembled from repeatable printed modules.

## Design Constraints

- Fit components on the print bed with minimal supports.
- Keep the modular structure stable when upright.
- Retain assembled sections while allowing relative rotation.

## Engineering Work

Developed male/female snap-fit proof-of-concept parts, base segments, pole sections, branches, hooks, and plugs that cover the joints.

## Outcome and Evidence

Connection prototypes and CAD files are documented; a complete loaded assembly test is not recorded.
