# Display Hooks

- **Year:** 2024
- **Context:** Personal project

## Summary

Designed a freestanding, 3D-printed display for six hanging memorabilia items, with an optional central display position. The geometry balances visual character, low material use, and fabrication with minimal supports.

## Objective

Display hookable memorabilia in a compact standalone structure.

## Design Constraints

- Provide six hooks and an optional central display position.
- Minimize material use and printing supports.
- Fit on the print bed and maintain an intentional appearance.

## Engineering Work

Modeled a single display structure in Fusion 360 around the required hook arrangement.

## Outcome and Evidence

A CAD file and display photo are available; load capacity is not specified.
